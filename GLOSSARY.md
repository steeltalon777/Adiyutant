# GLOSSARY

| Term | Definition |
|------|------------|
| Adiyutant | The product — a local-first organizer with an embedded AI agent |
| AdiyutantCore | Planned Rust local-first domain core |
| Check-in | A user's status update (morning, day, evening, shutdown) |
| DailyLog | The daily journal record containing check-ins, events, and state |
| Habit | A tracked behavior or routine (e.g., speech, exercise, reading) |
| HabitEvent | A single occurrence of a habit with level and status |
| ReminderDefinition | A scheduled reminder configuration |
| AlarmDefinition | A scheduled alarm configuration |
| TimerDefinition | A timer configuration (focus, rest, or custom) |
| CalendarEvent | A calendar event with time range and location |
| ContextDocument | A markdown document with user-defined context (goals, rules, routines) |
| ActionProposal | A suggestion from the agent or local rules, pending user confirmation |
| Agent Gateway | External layer for LLM routing, tool execution, and API key management |
| Sync | Future cross-device data synchronization |
| Local-first | Application works primarily with local data; server is optional |
| Platform Shell | A UI client that wraps Core with platform-specific behavior (Android, Web, Desktop) |
